Create ebook and PDF download forms with consent fields and protected links.

Features:

* Build forms with text, email, checkbox and privacy fields.
* Deliver configured files through protected links and optional confirmation emails.
* Export and delete contact data from the administration area.
* Render privacy information using the configured page.
* Form submission requires a valid nonce; exclude the form page from long-lived full-page caching.

== Description ==

Create ebook and PDF download forms with consent fields and protected links.

This edition uses native WordPress.org updates. There is no GitHub self-updater or external plugin installer. Updates become available after approval and publication in the directory.

Documentation and source: https://github.com/MichaelGahnDESIGN/MGD_Giveaway_WP-Plugin

Forms store submitted data locally and send email through wp_mail. Your configured email provider processes delivery. Configure consent and retention for your use. SMTP credentials belong in server configuration or a mail plugin.

== Installation ==

1. Upload the plugin folder or install the approved directory release from Plugins > Add New.
2. Activate the plugin and review its settings.
3. Test the configured features before enabling them on a production website.

== Frequently Asked Questions ==

= How are updates delivered? =
WordPress checks the official directory. This edition has no configurable update repository.

= Does it send analytics? =
No analytics or telemetry service is included. WordPress communicates with WordPress.org for native updates. Support links open only when clicked.
